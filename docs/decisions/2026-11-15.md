# 2026-11-15 ガイドの構成で決めたこと

## 見本アプリの保存名を変えた
`sample/index.html` のローカルストレージの保存名を `memos` から `chokottoMemoSample` に変えた。

### なぜ
ローカルストレージはパス単位ではなくサイト（akiyumeyou.github.io）単位で共有される。
元アプリ（/2024_2_kadai3/）と同じ保存名のままだと、見本でデモ中に追加・削除したメモが、講師が実際に使っているメモに混ざる。

## 見本アプリは jQuery なしの HTML1枚にした
元は css/style.css と jQuery が別ファイル。講座では「index.html 1枚をNetlify Dropに置く」流れなので、CSSを中に入れ、jQuery を使わない書き方に直した。動きは同じ。POTZのロゴとリンクは外した。

## スライドはHTMLで置いた
ガイドと同じURLから開け、参加者があとで見返せるようにするため。元はClaudeのスライド資料で、`slides/index.html` はその書き出し。
アイコンは絵文字に置き換えている。

## 図の読み込みに失敗しても動くようにした
全体の流れ図（mermaid）は外部から読み込む。読み込めないときにタブ切り替えや用語集まで止まらないよう、読み込めたときだけ初期化する。
