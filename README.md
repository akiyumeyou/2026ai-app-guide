# Geminiでつくる アプリ開発の基本のき（講座ガイド）

徳島生成AI部の講義「Geminiでつくる アプリ開発の基本のき」（前半30分・座学）の配布用ガイドです。自分で学習できるよう、資料・プロンプト・見本のソースコードを置いています。

公開URL（GitHub Pagesを有効にした場合）：https://akiyumeyou.github.io/2026ai-app-guide/

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | 配布用ガイド（仕組み・仕様書・作る・試す・公開する・チェックリスト・Q&A・用語集） |
| `sample/index.html` | 見本アプリ「ちょこっとメモ」。HTML1枚だけで動く版 |
| `slides/index.html` | 講座スライド（ブラウザで開く版）。← → キーで移動、N でノート、F で全画面 |
| `potz1.png`〜`potz5.png` | ガイドのマスコット画像 |
| `docs/decisions/` | 決めたことの記録 |

## 直すとき

- プロンプトや手順は `index.html` を直接編集します。
- 用語集は `index.html` の下のほうにある `GLOSSARY_TERMS` に1件足すだけで増やせます。
- スライドの元はClaudeのスライド資料です。`slides/index.html` はそこから書き出したもので、スライドを直したら書き出し直します。
